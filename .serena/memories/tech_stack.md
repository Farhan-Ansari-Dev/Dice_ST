# Tech Stack Architecture

- **Root Framework / Meta**: React Native Workspace with disconnected backend and admin panel monorepo approach
- **Package Manager**: npm/npx
- **Mobile Frontend**: Expo SDK (React Native), TypeScript, React Navigation with Native Stack, Bottom Tabs, and Drawer.
- **Admin Dashboard**: Vite, React DOM, Zustand State Management, Recharts Data Visualization, Tailwind/CSS.
- **Backend API**: Node.js, Express, TypeScript (ts-node-dev), MongoDB (Mongoose ORM).
- **Security / Auth**: JWT Strategy, bcryptjs encryption. 
- **Cloud Hooks**: AWS SDK (S3, SES, presigner), Cheerio parsers.
